# 手机 WebXR 遥操 UI 设计文档

> **适用范围**：
>
> * 手机 WebXR（无 hit-test）
> * Controller 模式（设备位姿即控制器）
> * 6DOF / 7DOF 机械臂通用
> * 交互范式：**Toggle + Clutch**

---

## 1. 设计目标

### 1.1 人体工效目标

* 单手握持手机
* 单拇指完成 ≥90% 操作
* 连续操作 ≥10 分钟不明显疲劳

### 1.2 系统目标

* 不依赖持续按压
* 不引入额外抖动源
* 与 IK / 控制算法完全解耦

---

## 2. 使用姿态假设

* **默认：右手持机，右拇指操作**
* 左手模式为左右镜像
* 设备方向：竖屏

---

## 3. 拇指自然区分析

### 3.1 区域划分

```text
┌──────────────────┐
│                  │
│   XR 主视野区    │  ← 禁止放置 UI
│                  │
│                  │
│                  │
│                  │
│                  │
│                  │
│      ◯ EE        │
│                  │
├──────────┬───────┤
│  MOVE    │ ROT   │  ← 拇指最舒适区
└──────────────────┴───────┘
```

* **最舒适区**：屏幕下方约 20–30%
* **禁止区**：屏幕上半（避免遮挡机械臂 / 末端）

---

## 4. 核心 UI 组件

### 4.1 主控制按钮（必选）

#### MOVE（TRANSLATE）

* 位置：左下
* 行为：

  * Tap：IDLE ↔ TRANSLATE（Toggle）

#### ROTATE

* 位置：右下
* 行为：

  * Tap：IDLE ↔ ROTATE（Toggle）

#### 尺寸规范

* 触控直径：≥14–16 mm
* 按钮间距：≥4 mm

---

### 4.2 Clutch（紧急脱离，无实体按钮）

#### 触发方式

* **双击屏幕任意位置**

#### 行为

```text
ANY STATE → IDLE
```

* 立即停止末端目标更新
* 清零 Δpose 积分

> Clutch 为高优先级输入，不占用拇指自然区。

---

## 5. 状态可视化反馈

### 5.1 按钮状态

| 状态        | MOVE | ROTATE |
| --------- | ---- | ------ |
| IDLE      | 灰    | 灰      |
| TRANSLATE | 高亮   | 灰      |
| ROTATE    | 灰    | 高亮     |

### 5.2 中央提示（建议）

* 当前模式文字：`MOVE` / `ROTATE`
* 半透明 EE 轴向 gizmo（仅显示，不可交互）

---

## 6. 交互原则（强约束）

* ❌ 不存在任何“持续按压即控制”逻辑
* ❌ 不存在推杆 / 摇杆式 UI
* ❌ 不提供 speed / gain 连续调节
* ✅ 所有控制均由 **设备位姿变化**驱动

---

## 7. 左手模式与设备适配

### 7.1 左手模式

* MOVE / ROTATE 按钮左右镜像
* 逻辑完全一致

### 7.2 大屏 / 平板

* 按钮尺寸同比放大
* 控制区高度可扩展至屏幕下方 30–35%

---

## 8. 与系统其他模块的边界

### UI 只负责

* 状态切换（Toggle / Clutch）
* 状态可视化反馈

### UI 不负责

* IK 权重
* 速度 / 限速
* 安全约束

---

## 9. 设计结论

> 该 UI 设计遵循工业级遥操系统的人体工效原则，
> 在移动端条件下最大化稳定性、可预测性与可持续操作能力。
